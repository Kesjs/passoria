## Périmètre validé

Une seule plateforme Passoria, couvrant : naissances, formalités administratives après décès, dossier unique réutilisable, ARCH Santé, identification SIM et accès universel Web/SMS/USSD/guichet. **SONEB Direct est exclu.** Démonstration MVP prioritaire : deux parcours naissance/décès, dossier fictif, précontrôle, suivi, espace agent et simulation USSD.
